# groundwerx-social

GroundWerx Digital's social content HQ. Shared by Tyler and Cade.

- `strategy.md`: who we're talking to, what we sell, voice, pillars, design rules. **Start here.**
- `calendar/log.md`: every post, who made it, and its status.
- `brand/`: logo and fonts.
- `templates/`: the code that renders post graphics.
- `images/`: finished post images. This repo is public so Metricool can pull them by link.

Image links follow this pattern:
`https://raw.githubusercontent.com/groundwerxdigital/groundwerx-social/main/images/<week>/<file>.jpg`
